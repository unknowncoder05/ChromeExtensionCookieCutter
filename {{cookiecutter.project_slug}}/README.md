## What Is Included

- Manifest V3 Chrome extension configuration.
- Background service worker for install events, browser action clicks, tab updates, and message routing.
- Popup UI with active-tab inspection and message calls into the background/content script.
- Options page backed by `chrome.storage.sync`.
- Content script that is injected on user action through `activeTab` and `chrome.scripting`.
- Shared settings and Chrome API helpers.
- Validation and build scripts that produce a loadable `dist/` directory.

## Development

```bash
npm install
npm run validate
npm run build
```

Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select `dist/`.

## Customization Points

| File | Purpose |
|---|---|
| `extension/manifest.json` | Permissions, optional host permissions, action, options page |
| `extension/background/service-worker.js` | Long-running extension coordination and browser events |
| `extension/content/content-script.js` | Page-level behavior |
| `extension/popup/` | Toolbar popup |
| `extension/options/` | Settings UI |
| `extension/shared/` | Reusable constants and Chrome API wrappers |
